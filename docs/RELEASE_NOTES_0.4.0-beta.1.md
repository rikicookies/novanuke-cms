# NovaNuke 0.4.0-beta.1

NovaNuke 0.4.0-beta.1 is the first public release of NovaNuke. Earlier development builds were private working snapshots and are not supported upgrade sources.

## Scope

This release establishes the public baseline for the NovaNuke core, bundled modules, themes, installer, migrations, security controls, backups, internationalization, membership features and extension APIs.

## Installation

Use a fresh installation and follow `INSTALLATION.md`. There is no supported upgrade path from private pre-release development snapshots.

## Future updates

Public upgrade compatibility begins with 0.4.0-beta.1. Future releases will document their supported source versions in `UPDATING.md`.
