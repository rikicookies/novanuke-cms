# Changelog

All notable public changes to NovaNuke are documented here. Private development snapshots that preceded the first public release are intentionally omitted.

## Source bundle: NovaLearn 1.0.0 (core 0.4.0-beta.1)

- NovaLearn public theme 1.0.0: consolidated active CSS, responsive navigation and scoped translation/accessibility corrections.
- News admin views resolve through a reserved namespace and protected layout.
- Pages Comments 1.5.3 availability correction retained. No schema or migration changes in this bundle.
- Distribution excludes local installation state, generated assets, uploads, caches and patch history files.

## 0.4.0-beta.1

- First public NovaNuke release.
- Establishes the supported baseline for future core, module and theme updates.
- Includes the web installer, administration system, modular content architecture, bundled modules, themes, access controls, internationalization, backups, maintenance and release validation tooling.
- Public upgrade history begins with this release.
